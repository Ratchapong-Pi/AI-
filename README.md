# 📖 MangaX AI - ระบบเว็บแปลภาษามังงะอัจฉริยะ (สำหรับอ่านคนเดียว)

เว็บแอปพลิเคชันสำหรับแปลภาษามังงะ มันฮวา และการ์ตูน (ญี่ปุ่น / เกาหลี / จีน / อังกฤษ -> ภาษาไทย) ขับเคลื่อนด้วย **Google Gemini Multimodal Vision AI** สไตล์แอป MangaX AI

---

## ✨ ฟีเจอร์หลัก (Features)

1. **ดึงรูปภาพจากลิงก์เว็บมังงะ (Manga Web URL Scraping & Proxy)**:
   - นำลิงก์ตอนมังงะจากเว็บมาใส่ ระบบจะตรวจหาและดึงรูปหน้าทั้งหมดมาให้อัตโนมัติ
   - มีระบบ Image Proxy ช่วยแก้ปัญหาติด CORS / 403 Forbidden / Hotlink Protection
2. **ตรวจจับบอลลูนและแปลอัตโนมัติ (AI Bubble OCR & Thai Localization)**:
   - ตรวจจับพิกัดกล่องคำพูด (Speech Bubbles), ช่องความคิด, คำบรรยาย และ SFX
   - ลบข้อความเดิมและแปะคำแปลภาษาไทยลงในบอลลูนอย่างแนบเนียน
   - ปรับแต่งฟอนต์ภาษาไทยได้ตามใจชอบ (Kanit, Prompt, Mali, Itim, Chakra Petch)
3. **ระบบสลับดูต้นฉบับทันที (Peek Raw Artwork)**:
   - กดปุ่ม **Spacebar** ค้างไว้ หรือคลิกปุ่ม "ดูต้นฉบับ" เพื่อซ่อนคำแปลและดูภาพวาดเดิมได้ทันที
4. **แก้ไขคำแปลได้แบบ Interactive (Inline Translation Editor)**:
   - คลิกที่บอลลูนคำพูดใดๆ เพื่อเปิดหน้าต่างดูภาษาดั้งเดิม (ญี่ปุ่น/เกาหลี), ก๊อปปี้, ฟังเสียงอ่าน (TTS), หรือแก้ไขข้อความแปลภาษาไทยได้แบบเรียลไทม์
5. **โหมดการอ่านหลากหลาย**:
   - 📜 **Webtoon Mode**: เลื่อนอ่านยาวแนวตั้ง สไตล์เว็บตูน
   - 📖 **Manga Mode**: เปิดทีละหน้า ซ้าย-ขวา พร้อมปุ่มคีย์บอร์ดนำทาง (A/D หรือลูกศร)
6. **ระบบแคช (Cache)**:
   - หน้าที่แปลแล้วจะถูกบันทึกแคชไว้ในเครื่อง อ่านซ้ำได้ทันทีไม่ต้องเสียโควต้า API ซ้ำ
7. **Export**:
   - สามารถกดบันทึกรูปภาพหน้านั้นพร้อมคำแปลภาษาไทยเป็นไฟล์ PNG ได้

## 🚀 วิธีเริ่มใช้งาน

### 1. การเปิดรันเซิร์ฟเวอร์
เปิด Terminal ในโฟลเดอร์ `c:\งาน\Antigravity\trans` แล้วสั่งรัน:
```bash
npm start
```
จากนั้นเปิดเว็บเบราว์เซอร์ไปที่: **`http://localhost:3000`**

### 2. ตั้งค่า Gemini API Key
1. คลิกที่ไอคอน **⚙️ ตั้งค่า (Settings)** ที่มุมขวาบนของหน้าเว็บ
2. นำ **Google Gemini API Key** (รับฟรีได้จาก [Google AI Studio](https://aistudio.google.com/app/apikey)) มาใส่ในช่อง
3. กดปุ่ม **"ทดสอบคีย์"** และกด **"บันทึกการตั้งค่า"**

### 3. เริ่มอ่านและแปลมังงะ
- **แบบใส่ลิงก์เว็บ**: คลิกปุ่ม *"เปิดมังงะ / ใส่ลิงก์"* -> แท็บ *"ลิงก์เว็บมังงะ"* -> ใส่ URL ตอนมังงะ -> กด *"ดึงรูปภาพ"*
- **แบบอัปโหลดรูปภาพ**: ลากไฟล์รูปภาพหน้ามังงะจากคอมพิวเตอร์มาวางในหน้าเว็บได้ทันที
- **แบบทดสอบตัวอย่าง**: คลิกแท็บ *"ตัวอย่างมังงะ"* เพื่อทดสอบแปลหน้ามังงะภาษาญี่ปุ่นตัวอย่างได้ทันที

## ⌨️ คีย์ลัด (Keyboard Shortcuts)

| ปุ่ม | คำสั่ง |
|---|---|
| **Spacebar (กดค้าง)** | ดูภาพต้นฉบับ (ซ่อนคำแปล) |
| **D หรือ → (Right Arrow)** | ไปหน้าถัดไป (ในโหมด Manga) |
| **A หรือ ← (Left Arrow)** | ย้อนกลับไปหน้าก่อนหน้า (ในโหมด Manga) |
| **T** | สั่งแปลหน้าที่กำลังดูอยู่ |
